# Portfolio (React + Vite + TypeScript)

## Run locally
```bash
npm install
npm run dev
```

## Customize
- Edit `src/data.ts`: name, pitch, about text, email, links, projects, skills.
- Put your resume at `public/resume.pdf`.
- Colors and fonts live at the top of `src/styles.css`.

## Deploy free (Vercel)
1. Push this folder to a GitHub repo.
2. Go to vercel.com, sign in with GitHub, Import the repo, Deploy.
3. You get `yourname.vercel.app`. Every `git push` redeploys.

Netlify and Cloudflare Pages work the same way (build command `npm run build`, output `dist`).
